# HerbChina Extracts — Official Website

Static company website for **HerbChina Extracts** (founded 2019, Xi'an, China),
supplier of botanical and mushroom extracts for overseas buyers.

## Structure

- `index.html` — single-page site: hero, products, quality, about, contact
- `styles.css` — all styling, no build step, no dependencies

## Deploy

Any static host works. With Vercel: import this repo, no build command needed,
output directory is the repo root.
